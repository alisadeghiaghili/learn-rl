Why this works

Invisible → visible

Git is invisible on the CLI; LearnGitBranching draws the tree. MDPs are worse — LearnRL draws the board, V, and π after every command.

Command golf

Every mutating command counts. Match par like git golf in LGB. Reset and undo keep the loop honest.

Levels, not lectures

Goals are checked live: reach a return, match V, match a policy. You learn by succeeding, not by finishing a video.
